# Lab

Design exploration for DexVision, kept for reference. Not part of the app.

- `npm run dev`: style guide, covers, palettes and icon variants (simulated data).
- `npm run build:soon`: rebuilds the public "Coming soon" page from `launch/` into `../../wwwroot`.

The design chosen for the app (Horizon, Gnoland palette, lite engine, storm icon) lives in `../frontend/src/design`.
